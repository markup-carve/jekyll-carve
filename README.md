# jekyll-carve

Jekyll converter for `.crv` pages, using the carve-lang gem 0.1.11 or later. It renders Carve pages through the native engine. Read the [Carve documentation](https://markup-carve.github.io/carve/) for the language syntax.

## Install

```sh
bundle add jekyll-carve
```

## Usage

```yaml
plugins:
  - jekyll-carve
```
