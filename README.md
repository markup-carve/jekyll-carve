# jekyll-carve

Jekyll converter for `.crv` pages, using the Carve 0.2 engine from carve-rb `next2` (unreleased). It renders Carve pages through the native engine. Read the [Carve documentation](https://markup-carve.github.io/carve/) for the language syntax.

## Install

```sh
bundle add jekyll-carve
```

## Usage

```yaml
plugins: [jekyll-carve]
```
